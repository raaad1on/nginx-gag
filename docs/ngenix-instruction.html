для NGENIX

Origin на образе nginx-gag:cdn-latest: HTTPS :443, реальные сертификаты, заглушка gag, xHTTP через unix socket.

Подключение Подготовка Установка Проверка
01

Подключитесь к серверу

Откройте терминал и войдите на origin-сервер по SSH под пользователем root.

SSH
ssh root@IP_СЕРВЕРА
02

Порт 443, сертификаты и сокет

Порт 443 должен быть свободен. Сертификаты — те же, что для nginx-gag.

Проверка порта и certs
ss -lntp | grep ':443' || echo "Порт 443 свободен"
ls -l /etc/nginx/ssl/fullchain.pem /etc/nginx/ssl/privkey.pem
mkdir -p /dev/shm/nginx
# Xray должен слушать: /dev/shm/nginx/cdn-xhttp.sock
ls -l /dev/shm/nginx/cdn-xhttp.sock || echo "Сокет ещё нет — поднимите xHTTP inbound"
Остановите старый Caddy/Nginx на 443 при конфликте: docker rm -f caddy nginx-cdn 2>/dev/null || true
В Xray inbound укажите listen /dev/shm/nginx/cdn-xhttp.sock и path, совпадающий с XHTTP_PATH.
03

Установите nginx-cdn

Скопируйте блок в SSH-терминал. Перед запуском поправьте DOMAIN и XHTTP_PATH под inbound.

install-nginx-cdn.sh
mkdir -p /opt/nginx-cdn /dev/shm/nginx
cd /opt/nginx-cdn

curl -fsSL -o docker-compose.yml \
  https://raw.githubusercontent.com/raaad1on/nginx-gag/cdn/docker-compose.yml.dist

# DOMAIN и XHTTP_PATH — как в Xray inbound
sed -i 's/DOMAIN=example.com/DOMAIN=YOUR.DOMAIN.TLD/' docker-compose.yml
sed -i 's|XHTTP_PATH=/api/v1/hs/edge/sigments.ts|XHTTP_PATH=/api/v1/hs/edge/sigments.ts|' docker-compose.yml

docker compose pull
docker compose up -d --force-recreate

sleep 2
docker ps --filter name=nginx-cdn
curl -sS https://127.0.0.1/health || true
DOMAIN FQDN origin, например:
node1.example.com
XHTTP_PATH Путь из inbound Xray, например:
/api/v1/hs/edge/sigments.ts
Unix socket Фиксированно:
/dev/shm/nginx/cdn-xhttp.sock
04

Проверьте результат

Проверка
curl -sS https://127.0.0.1/health
curl -f http://127.0.0.1:9000/health
ls -l /dev/shm/nginx/cdn-xhttp.sock
ss -lntp | grep -E ':443|:9000'
docker logs --tail 100 nginx-cdn
✓
Сервер готов.
В NGENIX укажите публичный IP origin и HTTPS-порт 443. Образ: ghcr.io/raaad1on/nginx-gag:cdn-latest.
NGENIX → HTTPS :443 → Nginx (cdn) → unix:/dev/shm/nginx/cdn-xhttp.sock → Xray xHTTP
